## Short project description

AI Native CRM is an experimental local-first desktop CRM that explores the Agent as the primary control surface. It combines evidence-aware reasoning with explicit capability, validation, and human-confirmation boundaries for CRM actions.

## Why this repository qualifies

AI Native CRM is a public MIT-licensed project exploring a reusable safety pattern for agent-operated business software: local-first data, explicit capabilities, validated writes, and human confirmation. I am the primary maintainer and actively ship, test, document, and triage the project. v0.2.1 has a clean lint gate, 3,433 passing frontend tests, 55 passing Rust tests, public CI, contribution guidance, and security reporting.
